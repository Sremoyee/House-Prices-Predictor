# 🏡 House Price Predictor (Linear Regression)

A simple machine learning project that predicts house prices based on house size using **Linear Regression**.  
Built using Python, Pandas, NumPy, Matplotlib, and Scikit-Learn.

---

## 📘 Overview
This project trains a Linear Regression model to learn the relationship between **HouseSize** (sq.ft) and **HousePrice**.  
Once trained, the model can predict the price of a house based on its size.

---
